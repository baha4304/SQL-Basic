# SQL-Basic
(혼자 공부하는 SQL)책을 통한 SQL 기초 공부

# 학습 내용
- 01. 주석달기, 데이터베이스 모델링 개념.sql
- 02. 테이블 만들고, 인덱스 생성하기, 뷰 만들기, 스토이드 프로시저 생성.sql
- 03. select 사용법(select, where, from).sql
- 04. select 사용법 심화, order by, limit, distinct, group by, having절.sql
- 05. 데이터변경, insert, update, delete 및 대용량 데이터 삭제하기.sql
- 06. MySQL의 데이터 형식(정수형, 문자형, 실수형, 날짜형, 변수설정, 형변환).sql
- 07. 두 테이블을 묶는 조인(내부조인, 외부조인, 상호조인, 자체조인).sql
- 08. SQL프로그래밍(if문, 변수설정, case문, while문, 동적SQL).sql
- 09. 테이블_만들기(gui로 만들기, SQL 언어로 만들기).sql
- 10. 테이블의 제약조건(기본키, 외래키, 고유키, 체크, 기본값,  not null).sql
- 11. 뷰의 개념(뷰의 생성, 수정, 삭제).sql
- 12. 인덱스 개념(클러스터형 인덱스, 보조 인덱스).sql
- 13. 인덱스의 내부 작동(클러스터형 인덱스, 보조 인덱스).sql
- 14. 인덱스의 실제 사용(create, drop index, 단순 보조 인덱스, 고유 보조 인덱스).sql
- 15. 스토어드 프로시저 사용법(입력 매개변수, 출력 매개변수, 동적 SQL).sql
- 16. 스토어드 함수(개념 및 사용, 커서 사용).sql
- 17. 자동 실행되는 트리거(트리거, old테이블, new테이블).sql
- 18. 파이썬과  sql 연동

# 개발 환경
